# JavaScript DOM and Event Handling

## About

This is a simple JavaScript project. I made this project to practice working with DOM and event handling in JavaScript.

The program changes the background color of boxes when clicked and displays the entered name next to the Hello heading after clicking the submit button.

## Technologies Used

HTML

CSS

JavaScript

## Features

Changes the background color of boxes on click

Displays the entered name next to the Hello heading

Uses click events

Takes user input using an input field

## JavaScript Used

Some basic JavaScript concepts used in this project are

DOM manipulation

querySelector()

querySelectorAll()

addEventListener()

textContent

value

forEach()

Functions

Event handling

## Operations Performed

1. Change Background Color

Changes the background color of a box when it is clicked.

2. Display Name

Displays the entered name next to the Hello heading when the submit button is clicked.

## How to Run

Create three files named index.html, style.css, and script.js.

Add the respective code to each file.

Open the index.html file in a browser.

Click on any color box to change its background color.

Enter a name and click the submit button to display the name.
